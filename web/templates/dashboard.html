X-API-KEY Yönetimi

Linklik servisini AI Ajanlarınıza (Claude Desktop, Cursor, LangChain vb.), otomasyon betiklerinize bağlamak için bu anahtarı kullanabilirsiniz.

🤖

Model Context Protocol (MCP) AI Ajan Entegrasyonu

Linklik, yerel MCP sunucusu ile donatılmıştır. Cursor veya Claude Desktop doğrudan link kısaltabilir, analitik okuyabilir, linkleri durdurabilir veya istatistiklerini sıfırlayabilir.

1. Cursor MCP Ayarı (.cursor/mcp.json)

{
  "mcpServers": {
    "linklik": {
      "url": "{{.BaseURL}}/mcp/sse",
      "headers": {
        "X-API-KEY": "{{.User.APIKey}}"
      }
    }
  }
}

2. Claude Desktop (claude_desktop_config.json)

{
  "mcpServers": {
    "linklik": {
      "command": "linklik",
      "args": ["--mcp", "--api-key", "{{.User.APIKey}}"]
    }
  }
}
Hazır MCP Araçları (Tools):
  • shorten_link: Yeni link kısaltma, özel alias, limit ve son kullanma tarihi belirleme.
  • list_links: Kullanıcı linklerini arama ve sayfalama ile listeleme.
  • get_link_analytics: Detaylı tıklanma, coğrafi ve cihaz istatistiklerini alma.
  • toggle_link: Linki tek tıkla durdurma veya yeniden aktifleştirme.
  • reset_link_stats: Tıklama sayacını ve tüm analitik geçmişini sıfırlama.
  • delete_link: Kısaltılmış linki kalıcı olarak silme.

REST API Örnekleri

1. Basit Link Kısaltma (cURL)

curl -X POST {{.BaseURL}}/api/v1/links \
  -H "X-API-KEY: {{.User.APIKey}}" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'

2. Dinamik QR Kod Alma

curl -X GET {{.BaseURL}}/api/v1/links/ozel-ad/qr?size=300 \
  --output qrcode.png
