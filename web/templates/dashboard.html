API Bağlantı Anahtarınız

Dışarıdan sistemimize bağlanmak, kendi otomasyonlarınızı veya yapay zeka ajanlarınızı (AI Agents) entegre etmek için aşağıdaki anahtarı kullanabilirsiniz. Her istekte X-API-KEY başlığı altında gönderilmelidir.

Harici API Kullanım Örneği

1. Link Kısaltma (cURL Örneği)

curl -X POST {{.BaseURL}}/api/v1/links \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: {{.User.APIKey}}" \
  -d '{
    "url": "https://google.com",
    "custom_alias": "arama-motoru",
    "max_clicks": 100
  }'

2. Link Düzenleme (cURL Örneği)

curl -X PUT {{.BaseURL}}/api/v1/links/arama-motoru \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: {{.User.APIKey}}" \
  -d '{
    "url": "https://google.com/search",
    "custom_alias": "google-arama",
    "max_clicks": 250
  }'

3. Detaylı Yardım Dokümantasyonu (cURL Örneği)

curl -X GET {{.BaseURL}}/api/v1/help \
  -H "X-API-KEY: {{.User.APIKey}}"

4. Analiz Verisi Çekme (cURL Örneği)

curl -X GET {{.BaseURL}}/api/v1/analytics/google-arama \
  -H "X-API-KEY: {{.User.APIKey}}"
